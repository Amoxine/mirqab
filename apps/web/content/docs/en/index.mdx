MIRQAB is the control plane around an open-source API gateway. From one dashboard you define
APIs, issue keys, set plans and quotas, and watch traffic. These pages open inside the dashboard
and follow the language you chose.

## Start here

- [Getting started](/docs/getting-started): publish your first API, issue a key and watch the traffic.
- [How a request travels](/docs/how-it-works): what a call passes through before it reaches your API.
- [APIs and OpenAPI import](/docs/apis-and-openapi-import): create, import and govern APIs.
- [Keys and plans](/docs/keys-and-plans): keys, plans, products, quotas and the status codes callers see.
- [Developer portal](/docs/portal): self-service for your developers.
- [Analytics and traffic](/docs/analytics-and-traffic): read the Dashboard, Analytics and Traffic.
- [Searching traffic](/docs/searching-traffic): find captured requests by content.
- [Roles, audit and tenants](/docs/roles-audit-tenants): permissions, the audit log and members.
- [Troubleshooting](/docs/troubleshooting): symptoms, causes and what to do.
