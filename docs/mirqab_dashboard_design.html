About the data

This workspace isn't connected to live telemetry, so every figure is sample data. Traffic, status mix, latency, error rate and region share follow the time range you pick. Node CPU and P95 are fixed samples, and round-trip times between nodes are typical values, not measurements. The clocks show real local time.
